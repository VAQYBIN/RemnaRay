# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[semantic versioning](https://semver.org/spec/v2.0.0.html).

Entries are generated from changesets when a release is cut (see
[`CONTRIBUTING.md`](CONTRIBUTING.md)). A release that needs an owner to do
something before upgrading says so under **⚠ Breaking**, **Migration notes**
and **Downgrade path**.
