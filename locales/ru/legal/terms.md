# Условия использования

Последнее обновление указывается на странице. Используя {brand} на сайте {domain},
вы соглашаетесь с условиями ниже.

## 1. Услуга

{brand} предоставляет доступ к сервису на срок, указанный в выбранном тарифе.
Описание тарифа, срок действия, лимит устройств и способы оплаты показываются
до подтверждения заказа.

## 2. Аккаунт

- Доступ выдаётся на аккаунт Telegram, с которого выполнен вход.
- Ссылка подписки предназначена для личного использования. Её можно сбросить
  в кабинете, если она стала известна третьим лицам.
- Лимит одновременных устройств определяется тарифом.

## 3. Оплата и продление

- Оплата принимается способами, включёнными владельцем магазина.
- Средства, зачисленные на баланс, используются только внутри магазина.
- Продление не выполняется автоматически, если это не указано в тарифе.

## 4. Возвраты

Возврат выполняется на внутренний баланс по решению владельца магазина, если
иное не требуется применимым законодательством. Запрос направляется в поддержку:
{support}.

## 5. Допустимое использование

Запрещено использовать сервис для действий, нарушающих применимое
законодательство, а также для рассылки спама, сканирования чужих сетей и атак
на сторонние ресурсы. При нарушении доступ может быть приостановлен.

## 6. Доступность

Сервис предоставляется «как есть». Возможны технические перерывы для
обслуживания. Владелец магазина не гарантирует непрерывную работу сторонних
сетей и провайдеров оплаты.

## 7. Изменения

Условия могут меняться. Актуальная редакция всегда опубликована на этой
странице; дата обновления указывается рядом с заголовком.

## 8. Контакты

Вопросы по условиям — {support}.
