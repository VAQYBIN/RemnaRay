# RemnaRay

RemnaRay is a Telegram-first subscription shop for Remnawave panels.

The repository uses Node.js 24.21+, pnpm 11.26.0, and Turborepo. Install the
pinned package manager with Corepack, then run:

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm lint
pnpm typecheck
```

The authoritative product specification is
[`docs/task/RemnaRay-TZ-full.md`](docs/task/RemnaRay-TZ-full.md).
